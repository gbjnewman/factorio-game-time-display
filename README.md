# Game Time Display

A lightweight, movable in-game time display for Factorio 2.1.

## Features

- Displays elapsed in-game time.
- Updates once every 60 ticks.
- Drag the display to reposition it.
- Right-click the display to reset its position.
- Configure its position through mod settings.

Time is measured using game ticks, not real-world time.
